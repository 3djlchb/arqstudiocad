# 0006. Internationalization: English source, translation packs

Date: 2026-10-11 · Status: Accepted

## Context

ArqStudioCAD targets users who already know AutoCAD-style command lines, in
many languages. IngeCAD (GPL-3.0) solved the same problem with a model that has
held up in practice; see its `docs/i18n.md`. We adopt it.

## Decision

**Everything the user reads is translatable; everything the user types is English.**

- English is the source language of code, docs and UI strings.
- Translations are **language packs**, one folder per language, discovered at
  runtime — adding a language changes no Python code and no test:

  ```
  i18n/
    en/  meta.json                        source language, empty catalog
    es/  meta.json  ui.json  commands.json
  ```

  `meta.json`: `{"code": "es", "name": "Español", "maintainer": "...", "maintained": true}`.
- `tr(source)` returns the translation or, if missing, the English source.
  Partial packs are valid and never block a release.
- Placeholders (`{count}`) must survive translation; a test checks every pack.
- **Command line:**
  - English command names and aliases always work, in every language;
  - a leading `_` forces the English (global) form, so scripts are portable;
  - a pack may *add* localized names (`LINEA`), never shadow an English name or alias.
- **Prompt options:** parsed against the English key; a translation keeps the
  key visible — `[Referencia(R)]`, `Centro(CE)`. A test checks every pack.
- The Rust core emits stable error codes and English technical messages only;
  Python produces translated user text.
- Qt's own dialogs are translated with Qt's shipped `.qm` files.
- **Spanish (`es`) is the first maintained language** and is held at 100 %
  coverage by tests; community packs are reported, not enforced.

## Consequences

- The i18n machinery is built in phase 1, with the first window, so packaging
  of language packs is tested on every platform from the start.
- Implementation may adapt IngeCAD's code; if it does, it is credited in
  `THIRD_PARTY.md`.
