## Logical widget hierarchy

This tree lists owned components and their visual placement, rather than
claiming every internal Qt child generated by Fusion or a layout.
Evidence: [main_window.py](../../python/arqstudiocad/ui/main_window.py),
`MainWindow.__init__`:76; [document_tabs.py](../../python/arqstudiocad/ui/document_tabs.py),
`DocumentTabs.__init__`:19; `WorkspaceSwitcher._widgets`:208.

```text
QApplication
└─ MainWindow : QMainWindow
   ├─ menuBar : File / Edit / View / Tools / Insert / Draw / Modify / Help
   ├─ top toolbars
   │  ├─ ribbon_bar_cad → Ribbon : QTabWidget (Ribbon layout)
   │  │  └─ page → RibbonGroupWidget → QToolButton grid + title QLabel
   │  ├─ toolbar_cad_* : Standard / Draw / Modify / Layers (Classic layout)
   │  └─ document_tabs → DocumentTabs.bar : QTabBar (only with documents)
   ├─ central _stack : QStackedWidget
   │  ├─ _welcome : QLabel
   │  └─ tabs : DocumentTabs / QStackedWidget → Viewport per document
   ├─ right dock group (default)
   │  ├─ LayersPanel → buttons + QTableWidget
   │  ├─ PropertiesPanel (tabbed with Layers) → PropertyGrid
   │  │  └─ caption QLabel + QTreeWidget / PropertyGridDelegate / editors
   │  ├─ BlocksPanel (tabbed with Layers; starts closed)
   │  │  └─ search QLineEdit + QListWidget + footer QLabel
   │  └─ HistoryPanel (split below Layers) → QListWidget
   ├─ bottom CommandWindow : QDockWidget
   │  └─ history QPlainTextEdit + prompt QLabel + input QLineEdit/QCompleter
   ├─ auto_hide_* : side QToolBars → SideTab buttons (when needed)
   ├─ Overlay : QFrame (one per unpinned dock, contents reparented)
   └─ statusBar
      ├─ normal status message
      └─ permanent busy QProgressBar / coordinates QLabel /
         DraftingBar (OSNAP, ORTHO) / workspace QToolButton
```
