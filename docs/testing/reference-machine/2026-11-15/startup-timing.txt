The fix: the message "Opened {name}: {count} entities" counts with
CadDocument.entity_count, as the Properties panel already did, instead of
len(get_entities()), which built every entity (block references drawn to
find their extents) on the GUI thread while the window was frozen. A test
opens every public sample and checks the count is the list's length.
