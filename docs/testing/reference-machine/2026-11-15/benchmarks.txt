== Quick TRIM/EXTEND on the floor: #188's pending validation

TESTING_AND_PERFORMANCE.md recorded #188's indexed edge lookup on a
development host and left the reference machine's check pending. The same
harness (crates/arq-core/benches/query.rs, SHA-256
f1572ee4c33a7526ab3a94563b06fd453369531373cd6aa4c8d396c302705b45) was
run here on #188's base, a2236f4 with that file copied in, and on main
22fe1e4, which holds #188 (`-- "TRIM EXTEND Quick"`, 20 samples):

  Unrelated lines  Operation  Base a2236f4   main 22fe1e4   main / base
  10,000           TRIM       10.964 ms      9.474 us       0.000864
  10,000           EXTEND     11.912 ms      7.026 us       0.000590
  100,000          TRIM       124.25 ms      10.276 us      0.0000827
  100,000          EXTEND     135.87 ms      7.376 us       0.0000543

On the floor the base cost an eighth of a second for each pick in a
100,000-line drawing; with the index the cost no longer grows with the
drawing (10,000 and 100,000 lines within 10 %).

second; the CPU in 92 ms, 11. The zoomed-in GPU case (23 ms) is slower
than the whole one; why was not looked into in this session.
