Method as in 2026-11-19/cursor-frames.txt: the real MainWindow,
1366 x 740 (a 1098 x 347 viewport), the renderer it chooses (OpenGL on
the GT 730) or the CPU through safe mode; 100000 generated entities on a
3-unit grid at 20 pixels a unit; synthetic QMouseEvent moves on a loop,
each sample a move plus a repaint, 60 samples after 3 warm-ups; "command"
at STRETCH's displacement prompt after base point 0,0. Each run had a
fresh XDG_CONFIG_HOME and QSettings folder, LANG=C.UTF-8,
QT_QPA_PLATFORM=xcb. Three rounds, the three commits and both renderers
alternated within each round. The 100 entities of row 50 (y = 150,
x = 3k):
  partial  ARCs, center (x+0.5,150), radius 0.5, 0 to 180 degrees; a
           crossing box of +-0.1 around each start (x+1,150).
  whole    the same ARCs, each wholly inside a crossing box.
  lines    LINEs (x,150)-(x+1,150), a crossing box around each end.
Then STRETCH 0,0 -> 2,3 was committed, checked and undone.
